# 제품 요구사항 · Stage 1
PR의 이유 → 입력 계약 → 처리 연결 → 검증을 한국어로 탐색한다. 연결 설정 → 데모 PR 목록 → Graph / Guided Flow / Code의 실행 가능한 경험이 이번 범위다.
실제 Git fixture baseline + PR 커밋 3개, 6개 이상 파일, 모의 Jira DEMO-1을 사용한다. Git 사실은 객체에서 읽고 설명은 명시적 MockProvider가 만든다. 계정 연결·실제 AI·CI 결과는 없다.
수용 기준: revision별 tree, 부모 대비 diff, rename/delete/revert, AST import 근거, URL 공통 선택, head 고정 투어, old/new 근거 이동, 읽음 복원, 스키마·참조 거부, loopback 인증, 브라우저 E2E.
전체 제품 로드맵: 2단계 GitHub/GHE 및 불변 수집, 3단계 Jira/CLI 어댑터, 4단계 실제 분석 UX 고도화, 5단계 복잡한 이력/규모/보안 검증. 이 문서는 그 단계를 완료했다고 주장하지 않는다.
